C language basic to advanced topics : 

c language all topic overview with only definitions:
    1. data types:
        - what is data type?
            - A data type is a classification that specifies the type of data a variable can hold, such as integer, floating-point, character, etc.
    2. variables:
        - what is a variable?
            - A variable is a named location in memory that stores a value of a specific data type.
    3. operators:
        - what is an operator?
            - An operator is a symbol that performs an operation on one or more operands (values or variables).
    4. control structures:
        - what is a control structure?
            - A control structure is a programming construct that determines the order in which statements are executed.
            - types of control structures:
                - Conditional statements: Used to make decisions based on certain conditions (e.g., if, if-else, switch).
                    - types of conditional statements:
                        - if statement: Executes a block of code if a specified condition is true.
                        - if-else statement: Executes one block of code if the condition is true and another block if the condition is false.
                        - else-if ladder: Allows multiple conditions to be checked in sequence.
                        - nested if statements: Allows an if statement to be placed inside another if statement for more complex decision-making.
                        - switch statement: Allows selection among multiple options based on the value of an expression.

                - Looping statements: Used to repeat a block of code multiple times (e.g., for, while, do-while).
                    - types of looping statements:
                        - for loop: Repeats a block of code a specified number of times.
                        - while loop: Repeats a block of code as long as a specified condition is true.
                        - do-while loop: Similar to the while loop, but guarantees that the block of code is executed at least once.

    5. jumping statements:
        - what is a jumping statement?
            - A jumping statement is used to transfer control from one part of the program to another.
            - types of jumping statements:
                - break statement: Exits the nearest enclosing loop or switch statement.
                - continue statement: Skips the remaining code in the current iteration of a loop and proceeds to the next iteration.
                - goto statement: Transfers control to a labeled statement within the same function.

    6. arrays:
        - what is an array?
            - An array is a collection of elements of the same data type, stored in contiguous memory locations.
            - types of arrays:
                - One-dimensional arrays: Used to store a list of elements.
                - Two-dimensional arrays: Used to represent matrices or tables.
                - Three-dimensional arrays: Used to represent data in three dimensions.

    7. functions:
        - what is a function?
            - A function is a block of code that performs a specific task and can be called from other parts of the program.
            - types of functions:
                - Built-in functions: Functions provided by the C standard library (e.g., printf, scanf, strlen).
                - User-defined functions: Functions created by the programmer to perform specific tasks.
                    - without parameters and without return value: Functions that do not take any input parameters and do not return any value.
                    - with parameters and without return value: Functions that take input parameters but do not return any value.
                    - without parameters and with return value: Functions that do not take any input parameters but return a value.
                    - with parameters and with return value: Functions that take input parameters and return a value.
                - Recursive functions: Functions that call themselves to solve a problem.
                - Inline functions: Functions defined with the inline keyword to suggest to the compiler to insert the function code directly at the call site for performance optimization.

    8. strings:
        - what is a string?
            - A string is a sequence of characters, typically used to represent text in a program.
            - types of strings:
                - String literals: A string literal is a sequence of characters enclosed in double quotes (e.g., "Hello, World!").
                - Character arrays: A character array is an array of characters that can be used to store strings.
                - String pointers: A string pointer is a pointer that points to the first character of a string.

    9. structures:
        - what is a structure?
            - A structure is a user-defined data type that allows you to group together variables of different types under a single name.
            - types of structures:
                - Self-referential structures: Structures that contain a pointer to the same structure type, allowing for the creation of linked data structures like linked lists and trees.
                - Nested structures: Structures that contain other structures as members.
                - Array of structures: An array that holds multiple instances of a structure.

    10. pointers:
        - what is a pointer?
            - A pointer is a variable that stores the memory address of another variable.
            - types of pointers:
                - Null pointer: A null pointer is a pointer that does not point to any valid memory location.
                - Void pointer: A void pointer is a pointer that can point to any data type, but cannot be dereferenced directly.
                - Function pointer: A function pointer is a pointer that points to a function, allowing you to call the function indirectly.
                - Pointer to pointer: A pointer to pointer is a pointer that stores the address of another pointer, allowing for multiple levels of indirection.

    11. file handling:
        - what is file handling?
            - File handling refers to the process of reading from and writing to files in a program.
            - types of file handling:
                - Text files: Text files are files that contain human-readable characters, typically used for storing text data.
                - Binary files: Binary files are files that contain non-human-readable data, typically used for storing complex data structures or multimedia content.


1. Introduction to C programming :
    - What is C language?
        - C is a general-purpose programming language that was developed in the early 1970s by Dennis Ritchie at Bell Labs.
        - It is a high-level language that provides low-level access to memory and hardware, making it suitable for system programming and embedded systems.
        - C is known for its efficiency, flexibility, and portability, allowing code to be compiled and run on different platforms with minimal changes.
   
    - History of C language:
        - Developed by Dennis Ritchie at Bell Labs in the early 1970s.
        - C was designed to be a general-purpose programming language that is efficient and flexible.
        - C has influenced many other programming languages, including C++, Java, and Python.
        
        - Importance of C language:
            - C is widely used in system programming, embedded systems, and application development.
            - C provides low-level access to memory and hardware, making it suitable for performance-critical applications.
            - C is a foundational language that helps programmers understand how computers work at a fundamental level.
            - C is a portable language, allowing code to be compiled and run on different platforms with minimal changes.
            - C is a widely supported language with a large community and extensive libraries, making it easier to find resources and support for development.
    
    - Features of C language:
        - Simple and easy to learn
        - Rich set of built-in functions
        - High-level language with low-level capabilities
        - Structured language
        - Case-sensitive
        - Portable and efficient

    - Structure of a C program
        - Basic structure of a C program:
            - #include <stdio.h> (Preprocessor directives)
            - #define (Macro definitions (gloabal declarations))
            - int main() (Main function)
            - declarations and statements (Variable declarations, Function definitions, etc.)
            - return 0; (Return statement)

    - Compilation process
        - The compilation process involves several steps:
            1. Preprocessing: The preprocessor handles directives like #include and #define, preparing the code for compilation.
            2. Compilation: The compiler translates the preprocessed code into assembly language.
            3. Assembly: The assembler converts the assembly code into machine code (object files).
            4. Linking: The linker combines object files and libraries to create an executable program.
            
    - Running a C program
        - To run a C program, follow these steps:
            1. Write the C code in a text editor and save it with a .c extension.
            2. Open a terminal or command prompt.
            3. Navigate to the directory where the C file is saved.
            4. Compile the code using a C compiler (e.g., gcc) with the command: gcc filename.c -o outputname
            5. Run the compiled program using the command: ./outputname (on Unix/Linux) or outputname.exe (on Windows)

    - Data types in C:

            - int: for integer values
            - float: for floating-point values
            - double: for double-precision floating-point values
            - char: for character values
            - void: for functions that do not return a value

    - Variables in C:
        - Variables are used to store data in a program.
        - A variable must be declared with a specific data type before it can be used.
        - Example of variable declaration:

3. Operators in C:
    - C provides various operators for performing operations on variables and values, including:
        - Arithmetic operators: +, -, *, /, %
        - Relational operators: ==, !=, >, <, >=, <=
        - Logical operators: &&, ||, !
        - Assignment operators: =, +=, -=, *=, /=, %=
        - Increment and decrement operators: ++, --
        - Bitwise operators: &, |, ^, ~, <<, >>
        - Ternary operator: 
                - syntax: condition ? value_if_true : value_if_false;    
        - Precedence and associativity of operators:
            - Operators have different levels of precedence, which determines the order in which they are evaluated in an expression.
            - Associativity defines the order in which operators of the same precedence level are evaluated (left-to-right or right-to-left).                
    
4. Control structures in C:
    - Conditional statements:
        - if statement: Executes a block of code if a specified condition is true.
            - syntax: 
                if (condition) {
                    // code to be executed if condition is true
                }

        - if-else statement: Executes one block of code if the condition is true and another block if the condition is false.
            - syntax: 
                if (condition) {
                    // code to be executed if condition is true
                } else {
                    // code to be executed if condition is false
                }

        - else-if ladder: Allows multiple conditions to be checked in sequence.
            - syntax: 
                if (condition1) {
                    // code to be executed if condition1 is true
                } else if (condition2) {
                    // code to be executed if condition2 is true
                } else {
                    // code to be executed if all conditions are false
                }

        - nested if statements: Allows an if statement to be placed inside another if statement for more complex decision-making.
            - syntax: 
                if (condition1) {
                    if (condition2) {
                        // code to be executed if both condition1 and condition2 are true
                    }
                }

        - switch statement: Allows selection among multiple options based on the value of an expression.
            - syntax: 
                switch (expression) {
                    case value1:
                        // code to be executed if expression equals value1
                        break;
                    case value2:
                        // code to be executed if expression equals value2
                        break;
                    default:
                        // code to be executed if expression does not match any case
                }

    - Looping statements:
        - for loop: Repeats a block of code a specified number of times.
            - syntax: 
                for (initialization; condition; increment/decrement) {
                    // code to be executed in each iteration
                }

        - while loop: Repeats a block of code as long as a specified condition is true.
            - syntax: 
                while (condition) {
                    // code to be executed as long as condition is true
                }

        - do-while loop: Similar to the while loop, but guarantees that the block of code is executed at least once.            
            - syntax: 
                do {
                    // code to be executed
                } while (condition);

5. Jumping statements in C:
    - break statement: Exits the nearest enclosing loop or switch statement.
        - syntax: 
            break;

    - continue statement: Skips the remaining code in the current iteration of a loop and proceeds to the next iteration.
        - syntax: 
            continue;

    - goto statement: Transfers control to a labeled statement within the same function.
        - syntax: 
            goto label;
            ...
            label:
                // code to be executed after the goto statement
                
6. Arrays in C:
    - Definition and declaration of arrays:
        - An array is a collection of elements of the same data type, stored in contiguous memory locations.
        - Arrays are declared by specifying the data type, followed by the array name and size in square brackets.
        - Example of array declaration:
            int numbers[5]; // declares an array of 5 integers

    - Accessing and modifying array elements:
        - Array elements can be accessed using their index, starting from 0.
        - Example of accessing and modifying array elements:
            numbers[0] = 10; // assigns 10 to the first element
            int firstNumber = numbers[0]; // retrieves the first element

    - Multidimensional arrays:
        - C supports multidimensional arrays, which are arrays of arrays.
        - Types of multidimensional arrays include:
            - One-dimensional arrays: Used to store a list of elements.
                - Example of one-dimensional array declaration:
                    int arr[5]; // declares an array of 5 integers

            - Two-dimensional arrays: Used to represent matrices or tables.
                - Example of two-dimensional array declaration:
                    int matrix[3][3]; // declares a 3x3 matrix

            - Three-dimensional arrays: Used to represent data in three dimensions.
                - Example of three-dimensional array declaration:
                    int cube[2][2][2]; // declares a 2x2x2 cube

            - Accessing and modifying elements in multidimensional arrays:
                - Elements can be accessed using multiple indices.
                - Example of accessing and modifying elements in a two-dimensional array:
                    matrix[0][0] = 1; // assigns 1 to the first element of the first row
                    int value = matrix[0][0]; // retrieves the first element of the first row   
            - Memory layout of arrays:
                - Arrays are stored in contiguous memory locations, allowing for efficient access and manipulation of elements.
                - The memory layout of a multidimensional array is row-major order, meaning that the elements of each row are stored in consecutive memory locations.
                - Example of memory layout for a 2D array:
                    int matrix[2][3] = {
                        {1, 2, 3},
                        {4, 5, 6}
                    };
6. functions in C:
    - Definition and declaration of functions:
        - A function is a block of code that performs a specific task and can be called from other parts of the program.
        - Functions are declared by specifying the return type, function name, and parameters (if any).
        - Example of function declaration:
            int add(int a, int b); // declares a function that takes two integers and returns an integer
    
    - Function definition and implementation:
        - A function is defined by providing the function body, which contains the code to be executed when the function is called.
        - Example of function definition:
            int add(int a, int b) {
                return a + b; // returns the sum of a and b
            }
               
    - Types of functions:
        - Built-in functions: Functions provided by the C standard library (e.g., printf, scanf, strlen).
            - provided by the C standard library (e.g., printf, scanf, strlen).
            
        - User-defined functions: Functions created by the programmer to perform specific tasks.
            - Types of user-defined functions:
                - without parameters and without return value: Functions that do not take any input parameters and do not return any value.
                    - syntax: 
                        void functionName() {
                            // code to be executed
                        }

                - with parameters and without return value: Functions that take input parameters but do not return any value.
                    - syntax: 
                        void functionName(int param1, float param2) {
                            // code to be executed using param1 and param2
                        }
                            
                - without parameters and with return value: Functions that do not take any input parameters but return a value.
                    - syntax: 
                        returnType functionName() {
                            // code to be executed
                            return value; // return statement
                        }

                - with parameters and with return value: Functions that take input parameters and return a value.
                    - syntax: 
                        returnType functionName(int param1, float param2) {
                            // code to be executed using param1 and param2
                            return value; // return statement
                        }

        - Recursive functions: Functions that call themselves to solve a problem.
            - Types of recursion:
                - Direct recursion: A function calls itself directly.
                    - Example:
                        void recursiveFunction() {
                            // code
                            recursiveFunction(); // direct call to itself
                        }

                - Indirect recursion: A function calls another function, which in turn calls the first function.
                    - Example:
                        void functionA() {
                            // code
                            functionB(); // calls functionB
                        }
                        
                        void functionB() {
                            // code
                            functionA(); // calls functionA
                        }

                - Tail recursion: A special case of recursion where the recursive call is the last operation in the function.
                    - Example:
                        int factorial(int n) {
                            if (n == 0) {
                                return 1; // base case
                            } else {
                                return n * factorial(n - 1); // recursive call
                            }
                        }

                - Non-tail recursion: A recursive function where the recursive call is not the last operation in the function.
                    - Example:
                        int fibonacci(int n) {
                            if (n <= 1) {
                                return n; // base case
                            } else {
                                return fibonacci(n - 1) + fibonacci(n - 2); // recursive calls
                            }
                        }

                - Mutual recursion: Two or more functions call each other in a circular manner.
                    - Example:
                        void functionA() {
                            // code
                            functionB(); // calls functionB
                        }
                        
                        void functionB() {
                            // code
                            functionA(); // calls functionA
                        }

                - Nested recursion: A recursive function that calls itself within another recursive call.
                    - Example:
                        int nestedRecursion(int n) {
                            if (n > 100) {
                                return n - 10; // base case
                            } else {
                                return nestedRecursion(nestedRecursion(n + 11)); // nested recursive call
                            }
                        }

                - Recursive functions with static variables: Functions that use static variables to maintain state across recursive calls.
                    - Example:
                        int staticRecursion(int n) {
                            static int count = 0; // static variable
                            if (n > 0) {
                                count++;
                                return staticRecursion(n - 1); // recursive call
                            } else {
                                return count; // return the count of recursive calls
                            }
                        }

                - Recursive functions with global variables: Functions that use global variables to maintain state across recursive calls.
                    - Example:
                        int globalCount = 0; // global variable
                        
                        int globalRecursion(int n) {
                            if (n > 0) {
                                globalCount++;
                                return globalRecursion(n - 1); // recursive call
                            } else {
                                return globalCount; // return the count of recursive calls
                            }
                        }

                - Recursive functions with local variables: Functions that use local variables to maintain state within each recursive call.
                    - Example:
                        int localRecursion(int n) {
                            int count = 0; // local variable
                            if (n > 0) {
                                count++;
                                return localRecursion(n - 1); // recursive call
                            } else {
                                return count; // return the count of recursive calls
                            }
                        }

                - Recursive functions with parameters: Functions that take parameters to control the recursion and pass data between calls.
                    - Example:
                        int parameterRecursion(int n, int count) {
                            if (n > 0) {
                                return parameterRecursion(n - 1, count + 1); // recursive call with updated count
                            } else {
                                return count; // return the count of recursive calls
                            }
                        }

                - Recursive functions with return values: Functions that return values to the caller, allowing the result of the recursion to be used in further computations.
                    - Example:
                        int returnValueRecursion(int n) {
                            if (n <= 1) {
                                return n; // base case
                            } else {
                                return returnValueRecursion(n - 1) + returnValueRecursion(n - 2); // recursive calls with return values
                            }
                        }

                - Recursive functions with multiple parameters: Functions that take multiple parameters to control the recursion and pass data between calls.
                    - Example:
                        int multiParameterRecursion(int n, int m) {
                            if (n <= 0 || m <= 0) {
                                return 1; // base case
                            } else {
                                return multiParameterRecursion(n - 1, m) + multiParameterRecursion(n, m - 1); // recursive calls with multiple parameters
                            }
                        }

                - Recursive functions with variable-length arguments: Functions that can accept a variable number of arguments, allowing for flexible recursion based on the number of inputs.
                    - Example:
                        #include <stdarg.h>
                        
                        int variableLengthRecursion(int count, ...) {
                            va_list args;
                            va_start(args, count);
                            int sum = 0;
                            for (int i = 0; i < count; i++) {
                                sum += va_arg(args, int); // retrieve each argument
                            }
                            va_end(args);
                            return sum; // return the sum of all arguments
                        }
                                                                                                                       
                 
        - Inline functions: Functions defined with the inline keyword to suggest to the compiler to insert the function code directly at the call site for performance optimization.    
            - syntax: 
                inline returnType functionName(parameters) {
                    // code to be executed
                }
            - Example:
                inline int square(int x) {
                    return x * x; // returns the square of x
                }
                    
7. Strings in C:
    - Definition and declaration of strings:
        - A string is an array of characters terminated by a null character ('\0').
        - Strings are declared as character arrays or using the char pointer.
        - Example of string declaration:
            char str[20]; // declares a string with a maximum length of 19 characters
            char *ptr = "Hello"; // declares a string using a pointer

    - String manipulation functions:
        - C provides several built-in functions for manipulating strings, including:
            - strlen(): Returns the length of a string.
            - strcpy(): Copies one string to another.
            - strcat(): Concatenates two strings.
            - strcmp(): Compares two strings.
            - strchr(): Finds the first occurrence of a character in a string.
            - strstr(): Finds the first occurrence of a substring in a string.  
            - strlower(): Converts a string to lowercase.
            - strupper(): Converts a string to uppercase.
            - strrev(): Reverses a string.
            
8. Structures in C:
    - Definition and declaration of structures:
        - A structure is a user-defined data type that groups related variables of different data types under a single name.
        - Structures are declared using the struct keyword.
        - Example of structure declaration:
            struct Person {
                char name[50];
                int age;
                float height;
            };

    - Accessing and modifying structure members:
        - Structure members can be accessed using the dot operator (.) for structure variables and the arrow operator (->) for pointers to structures.
        - Example of accessing and modifying structure members:
            struct Person person1;
            person1.age = 30; // assigns 30 to the age member
            strcpy(person1.name, "John"); // copies "John" to the name member

    - types of structures:
        - Self-referential structures: Structures that contain a pointer to the same structure type, allowing for the creation of linked data structures like linked lists and trees.
            - syntax: 
                struct Node {
                    int data; 
                };

        - Nested structures: Structures that contain other structures as members.
            - syntax:
                struct variable_name {
                    data_type variable_name;
                };

        - Array of structures: An array that holds multiple instances of a structure.
            - Example:
                struct Person people[10]; // declares an array of 10 Person structures

9. Pointers in C:
    - Definition and declaration of pointers:
        - A pointer is a variable that stores the memory address of another variable.
        - Pointers are declared by specifying the data type followed by an asterisk (*) and the pointer name.
        - Example of pointer declaration:
            int *ptr; // declares a pointer to an integer

    - Pointer arithmetic:
        - Pointers can be incremented or decremented to point to the next or previous memory location of the same data type.
        - Example of pointer arithmetic:
            ptr++; // moves the pointer to the next integer in memory
            ptr--; // moves the pointer to the previous integer in memory

    - Pointers and arrays:
        - Arrays and pointers are closely related, as the name of an array acts as a pointer to its first element.
        - Example of using pointers with arrays:
            int arr[5] = {1, 2, 3, 4, 5};
            int *ptr = arr; // points to the first element of the array
            printf("%d", *(ptr + 2)); // accesses the third element of the array

    - Pointers and functions:
        - Pointers can be passed to functions to allow for modification of variables or to pass large data structures efficiently.
        - Example of passing pointers to functions:
            void increment(int *num) {
                (*num)++; // increments the value pointed to by num
            }

10. File handling in C:
    - File operations in C:
        - C provides functions for performing file operations, including opening, reading, writing, and closing files.
        - Example of file operations:
            FILE *file = fopen("example.txt", "r"); // opens a file for reading
            if (file != NULL) {
                // read from the file
                fclose(file); // closes the file
            }

    - File modes:
        - C supports different file modes for opening files, including:
            - "r": Read mode (default)
            - "w": Write mode (creates a new file or truncates an existing file)
            - "a": Append mode (writes data at the end of the file)
            - "r+": Read and write mode
            - "w+": Write and read mode (creates a new file or truncates an existing file)
            - "a+": Append and read mode

    - Reading and writing files:
        - C provides functions for reading from and writing to files, including:
            - fprintf(): Writes formatted data to a file.
            - fscanf(): Reads formatted data from a file.
            - fputs(): Writes a string to a file.
            - fgets(): Reads a string from a file.
            - fwrite(): Writes binary data to a file.
            - fread(): Reads binary data from a file.
